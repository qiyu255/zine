🎨 主题模板示例

基于 CSS 变量与 Gruvbox 配色方案的主题切换系统

⚙️ 主题管理器功能

本模板内置 ThemeManager 全局对象，提供以下方法： 

ThemeManager.set('theme-dark')      // 手动设置深色主题
ThemeManager.set('theme-light')     // 手动设置浅色主题
ThemeManager.toggle()               // 切换当前主题
ThemeManager.followSystem()         // 清除手动设置，跟随系统
ThemeManager.getCurrent()           // 获取当前主题名称
ThemeManager.isManual()             // 检查是否手动设置过

手动设置的主题会持久化到 localStorage，刷新页面后依然生效。 点击右上角控件或直接在控制台调用上述方法即可切换主题。
